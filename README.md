Personal Portfolio Website

A modern, responsive portfolio website to showcase my projects, skills, and experience as a software development student.

⸻

🚀 Features
	•	Responsive Design: Adapts seamlessly to desktop, tablet, and mobile screens
	•	Hamburger Menu: For better navigation on mobile devices
	•	Sectioned Layout: About Me, Experience, Projects, Contact
	•	Project Gallery: Showcases recent projects with images, descriptions, and links to GitHub and blog posts
	•	Downloadable Resume
	•	Contact Section: Email, WhatsApp, and LinkedIn integration
	•	Custom Styling: Uses CSS and media queries for a clean, modern look

⸻

🛠️ Technologies Used
	•	HTML5
	•	CSS3 (with custom media queries)
	•	JavaScript (for mobile navigation)
	•	Font Awesome (icons)

⸻

🏗️ How to Use
	1.	Clone the repository:

git clone https://github.com/joywong1228/your-portfolio-repo.git
cd your-portfolio-repo


	2.	Open index.html in your browser.
	3.	Customize your information:
	•	Replace images in the /assets folder as needed
	•	Edit text (name, projects, experience, contact info) directly in the HTML
